## 这次修正

旧版只把原型放进展示 iframe 并改写已有链接，各稿菜单定义不同，主稿首页因此没有 Git 仓库菜单；部分脚本跳转仍进入旧详情。本版采用共享的正式产品菜单与路由，直接打开完整 HTML 页面，已移除 iframe 和侧栏底部演示快捷入口。

- 首次打开首页就有 Git 仓库、需求目录和完整正式菜单；每个产品页都使用同一菜单定义，当前页按所属功能高亮。
- Git 仓库 → 项目“进入” → 工作台为真实页面导航，浏览器后退/前进可回到概览、工作台、首页。
- 任务列表包含隔离任务和待交付任务入口。点击已执行的业务节点直接进入新版 `node/index.html`；执行现场、尝试与产出使用节点补充稿。返回按钮回到原任务，并恢复选中节点和画布视角。
- 最新任务隔离准备、工作区、交付面板继续使用 TD 补充稿；任务的“查看变更并交付”进入任务 Git 工作台，“查看变更并应用”进入非 Git 应用页。
- 主稿原有的执行现场/尝试入口也连接新版节点详情。待执行节点编辑、恢复、快照评审等专用区域继续保留。
- “项目详情 → 查看 Git”与“隔离准备 → 在需求画布查看”已接通。

## 产品内演示路线

1. **Git**：首页 → 左侧 Git 仓库 → 订单服务卡“进入” → 提交/差异、审查、修复 → 左侧主页。可用浏览器或顶部 ←/→ 后退和前进。
2. **节点详情**：任务列表 → 退款单分页查询与导出（T-2041，等待交付）→ 点击“实现接口”节点 → 新版执行现场 → 尝试与产出/历史/工具/阅读区 → 返回任务画布。
3. **Git 交付**：任务列表 → 退款单分页查询与导出 → 交付面板“查看变更并交付”→ 审阅差异 → 选择交付目标 → 分步确认提交、推送、创建 MR → 返回任务。
4. **非 Git 应用**：任务列表 → 月报改为按自然月汇总 → 查看变更并应用 → 三方比较与冲突 → 确认应用。工作区详情与清理仍在任务页。
5. **隔离准备**：左侧开始任务 → 确认计划 → 准备独立工作区 → 单独开始执行。工作区准备前后均为模拟。计划上的“在需求画布查看”可回到需求画布。
6. **其他补充**：知识库、PPT、职业、模板、恢复、数据库、设置及 B 类 15 项保留。特殊状态可在底部原型状态控件或顶部“原型目录”中打开。
