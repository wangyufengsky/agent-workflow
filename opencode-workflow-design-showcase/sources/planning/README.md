### 推荐路线（只用正式菜单与页面按钮）

1. **主线**：主页 → 左侧“开始任务”（PE01）→ 形成需求草稿（PE02）→ 生成计划（PE03 预览）→ 确认开始（PE05）→ ▶ 模拟服务事件 ×4（PE07 正文与工具 → PE08 部分草稿 → PE09 检查 → PE25 候选审阅）→ 逐项核对需人工判断 → 应用到草稿（PE31）→ 确认计划（PE32）→ 准备独立工作区 → 开始执行 → 任务画布。
2. **离开与回来**：规划中 → 左侧“任务列表”（PE14）→ 点该任务（PE15 补读，恢复选中与页签）→ 面包屑 / 浏览器后退回任务列表。
3. **停止与未知**：PE18 停止 → PE19 正在停止 → ▶ PE20 已停止；任务列表“待核对”→ PE21 → 核对原轮次；PE23 重启核对 → ▶ PE24 仅观察续接。
4. **执行中调整**：任务画布 → 调整待执行计划（PE33）→ ▶ 暂停回执 → 编辑区（PE34，在“导出 CSV 接口”后点 +）→ 保存（PE35）→ 重新确认 → 继续执行（恢复自动推进）。直接打开 PE34 可看领取竞态。
5. **固定模板**：左侧“模板任务”→ 创建固定任务 → PE36 只读。
6. **后续分期**：PE28 并行写冲突、PE37 大需求总览、PE38 有界局部细化（标“设计候选 · 后续分期”，确认 / 应用禁用并写原因）。
