## 设计要点（相对原稿新增）

1. **画布不动**：仍是 task.html 的大画布 + 480 右侧面板 + 「概览 / 执行现场 / 尝试与产出」三页签；点业务节点才打开，开始 / 结束为系统节点。切页签、开工具详情、开阅读区、切尝试都不重建画布、不改视口与选中。
2. **执行现场**：顶部「事实条」把 数据连接 / 模型正文 / 工具 / 尝试 / 结果与验收 分格显示，下一行用一句话解释组合（例如“正文传输已结束，结果尚未提交——这不代表这一步已完成”）。记录流按服务顺序排列模型正文（Markdown、未闭合代码块）、公开推理摘要（仅上游实际提供时出现）、工具调用卡（来源标签 + 调用 ID，同名多次分开，晚回原位更新）和服务事件 / 补读缺口。
3. **跟随最新**：开关 + 上翻自动暂停 + 「有新内容 · 回到最新」胶囊；展开、复制、打开工具或引用时不被追加打断；同一面板内按 节点 + 尝试 记住位置。
4. **工具详情**：面板内子视图，可展开到宽阅读区；参数 / 结果分区，JSON 树、带行号的代码 / 命令输出、分段读取、截断提示、空结果、读取失败；脱敏字段本身不进入数据，只显示「已隐藏 · 服务端脱敏」，复制同样不含；无权限 / 缺能力分别说明；没有重放或执行入口。
5. **尝试**：列表 → 单次详情 → 「查看这次的执行现场」；历史模式常驻只读条与「回到当前尝试」，结果 / 验收 / 产物都属于所选尝试，验收绑定结果版本与策略版本，历史区域没有执行动作。
6. **宽阅读区**：复用 run.html 的列表 + 阅读主体；显示所属节点 / 尝试 / 精确版本；引用定位到来源版本的精确行（不是最新文件），只有节选或摘要时明确标注、不伪造行号；失效 / 不存在 / 无权 / 尚未提供 / 不支持格式各有状态；下载按能力显示，失败不改变执行状态。
7. **异常**：取消中 / 已确认取消 / 取消结果未知、操作回执未知（只提供「核对原操作」，不重发）、断连 → 重连 → 补读 → 补读完成（去重计数）/ 缺口不可补、晚到响应 / 撤权 / 项目切换都不串内容。

## 隔离说明

- 不加载任何外部资源：去掉了原稿的 Google Fonts 链接，字体按 ds.css 回退栈显示（与原稿截图字形会有细微差异；侧栏品牌名在原型里缩小一号以保证一行显示）。
- 不调用 `window.workflowDesktop`、fetch、XHR、WebSocket、IPC，不写 localStorage / sessionStorage；主题和状态只走 URL 参数与内存。
- 样例数据全部虚构，不含真实项目数据或凭据；敏感字段在样例数据里就是「已隐藏」标记，不是被遮盖的真值。

## 自检

- 60 个状态 × 4 主题（1440×900）自动遍历：无 JS 错误、无非 `file://` 请求、面板 / 阅读区无横向溢出、设计样例标识可见；deepseek 另测 1280×800、1024×768。
- 25 项交互自测通过（跟随 / 暂停 / 回到最新、历史只读与归属、阅读区不重置画布、Esc 与方向键、脱敏复制、补读去重、晚回不串节点等），明细见 COVERAGE.md。
