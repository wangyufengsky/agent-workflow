opencode-workflow · deepseek 风设计稿

参照 DeepSeek Harness 的视觉语言，从产品角度逐页重新设计 opencode-workflow。每页都是可点击的原型，底部中间的“原型状态”可以切换加载、失败、结果未明等状态。业务规则（冻结身份、未知结果只读回读、抽屉宽度、草稿与执行分离）保持不变；布局、信息层级与交互按“美观、好用”重做。

一屏说清下一步每页先回答：现在怎样、要我做什么、下一步去哪。主操作只有一个，用主按钮胶囊（deepseek 风为白底黑字）。
少跳转，多就地常用选择直接铺在页面上（项目、流程），只有“更多”才进抽屉。
状态不靠颜色执行中 / 停滞 / 失败 / 未明 都是“图标 + 文字 + 颜色”；结果未明统一用虚线琥珀色。
原型控件与产品分离设计审阅用的状态切换不再混进产品页头，单独浮在底部中间。
四套皮肤

结构统一用 deepseek 风，其他三套只换颜色令牌。在这里选的皮肤会带到每个原型页；页内底部的“皮肤”下拉也能随时切换。
